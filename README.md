# IoT Electromagnetic Field Detector

## Overview
An IoT based EMF detection system using Arduino Nano and ESP32. 
The system detects electromagnetic field intensity, displays readings on OLED, monitors water level and sends alerts through Telegram.

## Features

- Electromagnetic field detection
- OLED display monitoring
- Water level detection
- Buzzer alert system
- ESP32 WiFi connectivity
- Telegram notification

## Hardware Used

- Arduino Nano
- ESP32
- OLED Display (SH1106)
- EMF Sensor/Antenna
- Water Level Sensor
- Buzzer

## Software

- Arduino IDE
- C/C++ Embedded Programming

## Working Principle

Arduino Nano collects sensor data and displays readings.
ESP32 receives data through UART and sends alert messages using Telegram API.
